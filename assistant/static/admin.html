Inviter quelqu'un

Le lien est à usage unique, valable 7 jours : la personne y choisit son mot de passe, puis le code de son téléphone.

Comment ça marche

Chaque personne est dans un groupe, qui lui donne ses droits. Admin a tout (y compris gérer les comptes et les réglages de la maison) et ne se modifie pas. Foyer accueille les nouveaux comptes. Une personne peut avoir quelques exceptions, sur sa fiche.
